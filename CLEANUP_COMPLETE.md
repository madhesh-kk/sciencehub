## Why Items Were Deleted

### Cache Folders
These are generated at build/development time and should NOT be in git:
- `.idea/` - IDE auto-generates
- `.vscode/` - Editor settings (keep source-controlled versions elsewhere)
- `.vite/` - Build cache, regenerated on `npm run dev`
- `node_modules/` - Generated by `npm install`, moved to frontend/
- `dist/` - Generated by `npm run build`, moved to frontend/

### Old Backend
- `spring-backend/` - Was restructured to `backend/`, old folder no longer needed

### Old Documentation
These were process documents from development and are obsolete:
- Bug fix summaries - Features are implemented and tested
- Design/redesign documents - Final designs are live
- Mobile testing notes - Documented in main README now
- Network setup guides - Not relevant for final project
